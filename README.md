# CampOn

Flutter mobile app for the CampOn camping recommendation service.

## Run

```sh
flutter run
```

## API

The app calls `https://campon.seohamin.com` using the Swagger contract at:

```text
https://campon.seohamin.com/api/swagger
```

Development questions and API gaps are tracked in `DEVELOPMENT_NOTES.md`.

## Login setup

OAuth provider console setup, server JWT contract, platform configuration, and
release checks are documented in [LOGIN_SETUP.md](LOGIN_SETUP.md).
